This guide takes you from account access to a tested agent. Complete the workflow in order because voice, knowledge, and telephony depend on a valid agent configuration.

## Before you begin

Confirm that you have access to the correct workspace, permission to create agents and knowledge bases, an active entitlement for the modules you need, and a working microphone for speech testing.

## Step 1 Sign in and select your workspace

Sign in using email and password or Google authentication. Complete email verification if prompted. If you belong to multiple organizations, select the workspace in which the agent should be created. Agents, knowledge bases, campaigns, phone numbers, billing, and permissions are organization-scoped.

## Step 2 Create the agent

Open **AI Voice Agents** and select **Create Agent**. Start from an available template or create the agent from scratch.

| Field | Guidance |
| --- | --- |
| Agent name | Use a recognizable operational name such as `Customer Support India` |
| Description | State the purpose, intended caller, and desired outcome |
| Agent type and industry | Select the closest supported workflow and sector |
| Language | Choose the main conversation language |
| Region and time zone | Match the business operation and calling schedule |
| Tone | Choose the communication style expected by the business |
| Icon | Select an icon that distinguishes the agent in lists |

## Step 3 Configure intelligence

Choose an available LLM provider and model. Configure response style and length for a phone conversation. Then review the system prompt. It should define the agent role, business identity, supported tasks, knowledge rules, output language, fallback behavior, escalation, and prohibited disclosures.

## Step 4 Configure communication

Set a short greeting and closing message. Select the voice provider, model or speaker, and speech rate. Play a sample before saving. Configure the transcription provider and model used to understand callers.

## Step 5 Add business knowledge

Create or connect a knowledge base. Add business information, products, services, FAQs, and approved documents. If website knowledge is enabled, add only authoritative pages. Remove obsolete content instead of leaving conflicting versions indexed.

## Step 6 Test the agent

Test a normal greeting, known FAQ, product question, unknown question, language switch, interruption, transfer request, and complete conversation. After the call, verify that the transcript, recording, summary, outcome, and usage data are correct where applicable.

## Step 7 Go live

For inbound service, acquire or select a phone number and map it through inbound or IVR configuration. For outbound service, create a campaign, choose the agent and number, import contacts, configure calling hours, and launch.

## Step 8 Monitor and improve

Review Agent Conversations, Campaign Call History, Speech API History, Platform Analytics, Credit Usage, and Account Activity. Re-test every material prompt, knowledge, voice, or routing change before returning the agent to production.

<Info>
  Setup progress shows that fields are completed. It does not prove that the agent is production-ready.
</Info>
