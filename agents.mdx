An **agent** is an AI assistant that communicates with customers on behalf of your business.

You can create agents for purposes such as:

- Customer support
- Sales enquiries
- Lead qualification
- Appointment requests
- Product information
- Service information
- Customer follow-up
- Outbound calling campaigns

Each agent can have its own name, language, tone, business knowledge, greeting, voice, and conversation rules.

<Frame caption="Choose a template or create a custom Valuez AI agent">
  ![Valuez AI agent template selection](/images/Img-2026-07-09-14-46-32.png)
</Frame>

<Info>
  Creating an agent does not automatically connect it to a phone number, campaign, website, or other channel. Configure and test the agent first, and then connect it using the appropriate Valuez AI feature.
</Info>

## Agent Setup Overview

Creating a working agent involves the following steps:

<Steps>
  <Step title="Define the agent's purpose">
    Decide what the agent should help customers with.
  </Step>
  <Step title="Create the agent">
    Start with a prepared template or create the agent from scratch.
  </Step>
  <Step title="Complete Agent Settings">
    Configure the agent's identity, response style, greeting, voice, and speech recognition.
  </Step>
  <Step title="Add business knowledge">
    Enter your business information, products, services, FAQs, and supporting documents.
  </Step>
  <Step title="Test the agent">
    Speak with the agent and confirm that its answers and voice are suitable.
  </Step>
  <Step title="Connect the agent">
    Use the agent with an available phone, campaign, website, or integration.
  </Step>
  <Step title="Review conversations">
    Check conversation history to understand how the agent is performing.
  </Step>

## Before You Create an Agent

Prepare the following information:

| Information | Example |
| --- | --- |
| **Purpose** | Answer customer questions about products |
| **Audience** | Existing customers in India |
| **Primary language** | English |
| **Agent name** | Customer Support Assistant |
| **Tone** | Professional and friendly |
| **Opening message** | “Hello, thank you for contacting Example Services. How may I help you?” |
| **Closing message** | “Thank you for contacting us. Have a good day.” |
| **Business information** | Address, contact details, and working hours |
| **Products or services** | Approved descriptions and prices |
| **Common questions** | Approved answers to customer FAQs |
| **Human-support process** | Support number, email, transfer, or callback process |

<Tip>
  Give each agent one clear main purpose. A focused agent is easier to configure, test, and improve.
</Tip>

## Agent Name

Choose a name that helps your team immediately recognize the agent's purpose.

Good examples:

- Customer Support Assistant
- Appointment Booking Assistant
- Product Enquiry Agent
- Admissions Helpdesk
- Renewal Reminder Agent
- Sales Qualification Agent

Avoid unclear names such as:

- Agent 1
- New Agent
- Testing
- Final Agent
- New Bot

A useful naming format is:

```text
[Purpose] - [Language]
```

Example:

```text
Customer Support - English
```

If you maintain separate test and live agents, include that in the name:

```text
Customer Support - English - Test
Customer Support - English - Live
```

## Language

Select the main language the agent should use.

If the form allows additional languages:

- Select only languages your business supports
- Confirm that a suitable voice is available
- Test every selected language
- Test customers who switch between languages
- Confirm product and company names are pronounced correctly

<Warning>
  A selected language must also work with the options chosen in **Voice & Audio** and **Speech to Text**. Always perform a voice test.
</Warning>

## Tone

Tone describes how the agent should sound.

| Use case | Suggested tone |
| --- | --- |
| Customer support | Patient and reassuring |
| Sales enquiries | Friendly and confident |
| Appointment requests | Clear and courteous |
| Payment reminders | Respectful and direct |
| Technical assistance | Calm and precise |
| Education enquiries | Helpful and encouraging |

Tone is a general guide. Use **Agent Instructions** when you need more specific behavior.

For example:

```text
Speak politely, use short sentences, and ask one question at a time.
```

---

## Description and Agent Instructions

The creation form requires at least **10 words**.

Describe:

- Who the agent represents
- Who it helps
- What it can do
- What result it should achieve

Weak example:

```text
This is a support agent.
```

Better example:

```text
This agent helps existing customers understand our services, working hours,
support options, and approved troubleshooting steps.
```

Another example:

```text
This agent speaks with prospective customers, understands their requirements,
and records requests for a sales-team callback.
```

## AI Model

The **AI Model** section controls how the agent prepares its answers.

<Frame caption="Choose the AI settings used for agent responses">
  ![Valuez AI AI Model settings](/images/Screenshot-from-2026-07-09-18-18-59.png)
</Frame>

### Settings

| Setting | What it controls |
| --- | --- |
| **AI Provider** | The available AI service used by the agent |
| **AI Model** | The response option available from the selected provider |
| **AI Response Style** | How consistent or varied the replies should be |
| **Maximum words per response** | How long an individual reply can be |
| **Knowledge Base** | Which business knowledge the agent should use |

The available providers and models can vary. Select from the options displayed in your workspace.

### AI Response Style

| Setting direction | General result |
| --- | --- |
| **Lower** | More consistent and predictable replies |
| **Higher** | More varied and flexible replies |

Use a lower response style when accuracy and consistency are especially important, such as:

- Customer support
- Appointment requests
- Product information
- Policy questions
- Lead qualification
- Information collection

Use a higher value carefully and test the results before customer use.

### Maximum Words per Response

Short responses generally work better for voice conversations.

Recommended approach:

- Answer simple questions in one or two sentences
- Ask one question at a time
- Give instructions one step at a time
- Ask whether the customer wants additional details
- Avoid reading long documents aloud

## Agent Instructions

Agent Instructions explain how the agent should behave.

They can define:

- The agent's role
- Its main objective
- Questions it should ask
- Actions it can and cannot perform
- What to do when information is missing
- When to offer human assistance
- How to end the conversation

Example:

```text
You are a customer-support assistant for Example Services.

Help customers understand our approved services, business hours, locations,
and support process. Use short, polite responses and ask one question at a time.

Use the Knowledge Base for business information. If confirmed information
is unavailable, do not guess. Explain that the information requires
confirmation and offer the approved support option.

Do not request passwords, one-time passwords, or payment-card details.
Do not promise a refund, appointment, transfer, or callback unless it has
been confirmed.
```

## Conversation Settings

The **Conversation Settings** section controls the beginning and ending of the conversation.

<Frame caption="Configure the agent's greeting and ending messages">
  ![Valuez AI Conversation Settings](/images/Screenshot-from-2026-07-09-18-35-42.png)
</Frame>

Both fields are required:

| Field | Purpose |
| --- | --- |
| **Greeting Message** | The first message the agent delivers |
| **Ending Message** | The message the agent uses before ending |

### Greeting Message

A good greeting should:

- Identify the business or service
- Be short
- Tell the customer how the agent can help
- Invite the customer to speak

Inbound example:

```text
Hello, thank you for calling Example Services. How may I help you today?
```

Outbound example:

```text
Hello, this is the automated assistant from Example Services calling about
your recent enquiry. Is this a convenient time to speak?
```

### Ending Message

A good ending should:

- Thank the customer
- Confirm the next step accurately
- Avoid introducing a new topic
- Avoid making an unsupported promise

Example:

```text
Thank you for contacting Example Services. Our team will review your request.
Have a good day.
```

<Warning>
  Do not say that an appointment, refund, transfer, payment, or callback is confirmed unless the corresponding action was actually completed.
</Warning>

## Voice & Audio

The **Voice & Audio** section controls how the agent sounds.

<Frame caption="Select and preview the agent's voice">
  ![Valuez AI Voice and Audio settings](/images/Screenshot-from-2026-07-10-17-17-21.png)
</Frame>

### Voice Settings

| Setting | Purpose |
| --- | --- |
| **Voice Provider** | Selects an available group of voices |
| **Voice** | Selects the voice customers will hear |
| **Speaking Speed** | Controls how quickly the agent speaks |
| **Voice preview** | Plays a sample of the selected voice |

### Choose a Voice

Listen for:

- Clear pronunciation
- Natural tone
- Suitable language
- Comfortable speaking speed
- Correct company-name pronunciation
- Correct product-name pronunciation
- Clear numbers and dates
- Suitability for your customers

<Tip>
  Do not test only with the sample phrase. Use **Test Agent** to ask questions containing real company names, product names, prices, addresses, dates, and telephone numbers.
</Tip>

### Speaking Speed

Use a slower voice when:

- Customers may need more time to understand
- The agent reads numbers or codes
- The business uses complex words
- Telephone audio quality may be inconsistent

Use faster speeds carefully. A voice that sounds acceptable in a short sample can feel rushed during a complete conversation.

## Speech to Text

The **Speech to Text** section controls how the agent recognizes customer speech.

<Frame caption="Choose how the agent recognizes spoken questions">
  ![Valuez AI Speech-to-Text settings](/images/Screenshot-from-2026-07-10-17-18-21.png)
</Frame>

Required settings include:

| Setting | Purpose |
| --- | --- |
| **Speech-to-Text Provider** | Selects an available speech-recognition option |
| **Speech-to-Text Model** | Selects the recognition model |
| **Allow Interruptions** | Lets customers speak while the agent is talking |

The current interface indicates support for English, Hindi, and Marathi with automatic language detection for the displayed supported configuration.

<Note>
  The languages available can depend on the selected option. Test every language you plan to use.
</Note>

### Allow Interruptions

When interruptions are enabled, customers can speak before the agent finishes.

Test interruptions using:

- A quiet room
- Moderate background noise
- Headphones
- Laptop speakers
- Short phrases such as “wait” or “okay”
- A complete new question

If the setting is too sensitive, background noise may interrupt the agent. If it is not sensitive enough, customers may find it difficult to interrupt.

## Troubleshooting

### Create Agent Is Disabled

Check:

- Whether you have permission to create agents
- Whether your plan's agent limit has been reached
- Whether the correct workspace is selected

If necessary, contact the workspace owner.

---

### Agent Does Not Appear

Try the following:

1. Clear the search field.
2. Return to the first page.
3. Refresh the browser.
4. Confirm the selected workspace.
5. Ask the workspace owner to verify your access.

---

### Cannot Complete Agent Creation

Confirm that:

- Agent Name is entered
- Language is selected
- Region is selected
- Time Zone is selected
- Industry is selected
- Tone is selected
- Description contains at least 10 words
- An icon is selected

---

### Time Zone Is Empty

Select the region first. The time-zone list depends on the selected region.

If you change the region, select the time zone again.

---

### AI Model List Is Empty

Try:

1. Select the AI Provider again.
2. Wait for the available options to load.
3. Choose an AI Model.
4. Refresh the page if the options still do not appear.
5. Contact your workspace owner if no option is available.

---

### Voice List Is Empty

Check:

- A Voice Provider is selected
- The provider is available
- A suitable voice exists for the selected language
- The voice list finished loading

Use the retry option if Valuez AI displays an error.

---

### Knowledge Base Required

The agent cannot be tested until a Knowledge Base is selected.

Open **Agent Settings → AI Model**, select the correct Knowledge Base, save the change, and return to **Test Agent**.

---

### Configuration Incomplete

Complete the missing fields in:

- Voice & Audio
- Speech to Text

The warning message lists the fields that require attention.

---

### Agent Gives an Incorrect Answer

Check:

1. Is the correct Knowledge Base selected?
2. Does the correct answer exist?
3. Is the information current?
4. Do two sources contain different answers?
5. Did the agent understand the customer's speech correctly?
6. Were the latest changes saved?
7. Does the agent need a clearer FAQ or instruction?

Correct the relevant section and start a fresh test conversation.

---

### Agent Cannot Understand Speech

Check:

- Selected language
- Speech-to-Text settings
- Microphone quality
- Background noise
- Speaking volume
- Speakerphone echo
- Pronunciation of names or technical terms

Compare what was spoken with the USER message shown in the test transcript.

---

### Agent Speaks Too Quickly or Slowly

Open **Voice & Audio**, adjust the speaking speed, save, and test again.

Use complete sample questions rather than relying only on the short voice preview.

---

### Changes Are Not Reflected

1. Confirm the save operation completed.
2. Check for an error message.
3. Refresh the page.
4. Confirm you edited the correct agent.
5. Confirm you are in the correct workspace.
6. Reset the test conversation.
7. Start a new test session.

    Customers can follow short answers more easily during voice conversations.
  </Accordion>

  <Accordion title="Keep business information in the Knowledge Base">
    Use Agent Instructions for behavior and the Knowledge Base for products, services, prices, hours, and policies.
  </Accordion>

  <Accordion title="Test after every important change">
    Changes to the language, voice, instructions, knowledge, or AI settings can affect customer conversations.
  </Accordion>

  <Accordion title="Review conversation history">
    Real conversations show where information or instructions need improvement.
  </Accordion>

  <Accordion title="Do not make unsupported promises">
    An agent should not confirm an appointment, transfer, refund, payment, or callback unless the action was completed.
  </Accordion>

  <Accordion title="Protect sensitive information">
    Never place passwords, secret keys, payment-card details, or confidential records in the agent's instructions or knowledge.
  </Accordion>
</AccordionGroup>
