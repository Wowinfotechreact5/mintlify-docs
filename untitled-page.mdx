Valuez AI is a voice and conversational automation platform for creating, operating, and monitoring AI agents that interact with customers across supported communication channels.

The platform brings together AI agents, business knowledge, voice calling, outbound campaigns, speech services, integrations, analytics, workspace management, and usage monitoring in one system.

This documentation explains how to use Valuez AI safely and effectively based on the capabilities available in the current platform.

---

## What You Can Do with Valuez AI

Valuez AI supports the following primary workflows:

- Create and configure AI agents
- Train agents using business knowledge
- Test agent responses before production use
- Review agent conversations and call activity
- Handle inbound customer calls
- Initiate outbound calls
- Create and monitor calling campaigns
- Manage campaign leads and call outcomes
- Review platform analytics
- Connect external applications through integrations
- Use Speech-to-Text and Text-to-Speech services
- Manage connected phone numbers
- Review speech API activity
- Invite workspace members
- Review account activity
- Manage profile and security information
- Compare subscription plans
- Maintain billing information
- Monitor and export credit usage
- Report platform problems
